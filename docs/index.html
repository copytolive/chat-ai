01

Nyalakan scanner

GitHub Pages adalah UI statis. Runtime WhatsApp/QR dijalankan di GitHub Codespaces. Setelah Codespace siap, scanner membuka halaman /wa-scanner/ secara otomatis di tab browser baru.

START WHATSAPP SCANNER
02

Scan QR

Tunggu tab WhatsApp Scanner terbuka. Jika browser memblokir tab otomatis, klik PORTS → WhatsApp Scanner (3847) → Open in Browser. Lalu buka WhatsApp → Linked devices → Link a device dan scan QR.

03

Test auto-reply

Setelah status berubah menjadi CONNECTED · AUTO-RUN · LAUNCH READY, kirim pesan dari nomor WhatsApp lain. Agent membalas otomatis.
